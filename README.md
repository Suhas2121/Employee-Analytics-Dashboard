# Employee Analytics Dashboard

## Project Overview
Developed an interactive Employee Analytics Dashboard using MySQL and Microsoft Power BI to analyse employee information, salary distribution, department-wise workforce and job-role distribution.

## Tools & Technologies
- MySQL
- MySQL Workbench
- Microsoft Power BI
- DAX
- SQL

## Dashboard Features
- Total Employees
- Total Salary
- Average Salary
- Lowest Salary
- Highest Salary
- Employee Count by Department
- Employee Distribution by Job Role
- Average Salary by Job Role
- Department-wise Salary Distribution
- Top 5 Highest-Paid Employees

## Interactive Features
- Department slicer
- Job Role slicer
- Hiring Date slicer
- Dynamic KPI cards and charts

## Key Skills Demonstrated
- SQL data retrieval and analysis
- Data modelling
- DAX measures
- Data visualization
- Interactive dashboard development
- Business data analysis

## Project Files
- Power BI dashboard (.pbix)
- Dashboard PDF
- Dashboard screenshots

## Project Objective
To transform employee data into meaningful visual insights that help understand workforce distribution and salary patterns.
